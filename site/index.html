Features

Everything stays on one canvas

Ink, code, and a live application in the same place, so the explanation never breaks to switch windows — recording a lesson or standing at a projector.

  • Pen-first ink Pressure-aware strokes with palm rejection, tuned for Wacom and Surface pens.
  • Unbounded canvas Pan with touch, pinch to zoom, and never run out of room mid-explanation.
  • Live application capture Embed any window or display on the board and keep drawing over it.
  • DAX and SQL containers Text blocks with syntax highlighting, and F6 to format the code in place.
  • Portable board files Boards save as .wboard — Explorer and VS Code show the embedded preview.
  • Native and yours A Windows application, not a service: no account, no tenant, no retirement date.
