Pen

Pen tipCurrent tool. Pen is selected at startup.
Pen hoverShow the small red pointer dot and hide the arrow.
Pen contactHide both the pointer dot and the arrow.
Pen eraserErase complete strokes.

Mouse

MovementA physical mouse shows the normal arrow.
Left buttonSelect, move, or resize a container. Release returns to the previous drawing tool.
Resize handleDrag the circular bottom-right handle. Aspect ratio is preserved.
WheelZoom at the pointer.
Middle buttonPan.
Right buttonPan while held. Release returns to Pen.

Touch

One fingerPan. Suspended while the pen is in contact.
Two fingersPan and pinch zoom.

Keyboard

SpacePan while held.
Ctrl+Z / Ctrl+YUndo / redo.
Ctrl+VPaste an image, or create a text container from plain text.
Ctrl+CCopy the selection. Copying a LiveView copies its last frame as a bitmap.
Ctrl+S / Ctrl+OSave / open a board.
Shift+F12Save As. Commits an active text edit first.
DeleteDelete the selected container and its linked strokes.
F2Edit the selected text container.
F6Format DAX or SQL Server code in an active text edit.
Ctrl+EnterCommit the text edit and return to display mode.
EscapeCancel the text edit, or leave full screen when not editing.
Alt+LLaser pointer.
F11Toggle full screen.

Double-click

On a containerCenter it and fit it to the canvas.
On empty canvasCenter and fit all content, or reset an empty board.

Tools menu

PenPressure-aware ink. Selected at startup.
HighlighterTranslucent stroke. Marks a line without covering it.
CalligraphyA nib that responds to direction, for labels and arrows.
Laser pointerPointer for the projector. Does not write to the file. Alt+L.
Preferences…Searchable settings: startup monitor, full screen, laser trail, toolbar.
Add LiveView…Capture an application window or display as a container.
Freeze LiveViewFreeze or resume the selected live feed.
Reconnect LiveView…Pick a new capture target for the existing container.
Import (toolbar)Add a .wimport recipe or an image at the top-left of the view.
